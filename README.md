# VoidCases 3.1.0 ULTRA

Отдельная ветка обновления кейсов для сервера VoidMain. Совместимость: Paper 1.21.11, Java 21.

## Что добавлено в этой ветке
- Анимированная рулетка с предметами из таблицы наград.
- Постепенное замедление прокрутки и звуковые щелчки.
- Фиолетовая тема VoidMain, финальная вспышка частиц и звук выигрыша.
- Награда сначала сохраняется в очереди, затем выдаётся после анимации.
- Если инвентарь заполнен, оставшиеся предметы выпадают рядом с игроком.
- Существующая логика независимых шансов и ежедневных наград сохранена как основа.

## Команды
- `/wcases give <игрок> <ordinary|epic|legendary> [количество]`
- `/wcases daily`
- `/wcases reload`
- Алиасы: `/voidcases`, `/кейсы`

## Сборка
GitHub Actions запускается при push в ветку `voidcases-3.1-ultra` или вручную через **Actions → Build VoidCases ULTRA → Run workflow**. Скачай артефакт `VoidCases-3.1.0-ULTRA`.

Локальная сборка: Java 21 + Maven, команда `mvn --batch-mode clean package`. Результат: `target/VoidCases-3.1.0-ULTRA.jar`.

Перед установкой сделай резервную копию папки плагина и проверь JAR на тестовом сервере. Эта ветка основана на исходниках Reborn; она не переносит автоматически неизвестные закрытые/скомпилированные части исходного Void-cases 3.0.0.
