# WertySMP-Cases-Reborn

Исходный проект плагина для Paper 1.21.11 и Java 21.

## Автоматическая сборка
Каждый push в `main` запускает GitHub Actions. Открой вкладку **Actions**, выбери успешный запуск **Build plugin**, а внизу страницы скачай артефакт **WertySMP-Cases-JAR**. Внутри ZIP будет `WertySMP-Cases-2.1.0.jar`.

## Команды
- `/wcases give <игрок> <ordinary|epic|legendary> [количество]` — выдать кейсы (право `wertysmpcases.admin`).
- `/wcases daily` — открыть ежедневные награды.
- `/wcases reload` — перезагрузить конфигурацию.

## Важно
Сначала тестируй на копии сервера. Не заменяй рабочий JAR до проверки. Конфигурация наград находится в `plugins/WertySMP-Cases/config.yml` (при первом запуске файл обычно создаётся в папке плагина).

Шансы наград проверяются независимо: несколько предметов могут выпасть за одно открытие. Настройка шанса — процент от 0 до 100.
